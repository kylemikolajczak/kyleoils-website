# Loyalty Rewards Program

The doTERRA Loyalty Rewards Program is a recurring order program where members can earn Loyalty Points that can be redeemed for doTERRA products.

## Why this term matters

LRP can make sense if you use products regularly and want to make ordering more planable.

## Kyle Oils context

Kyle Oils explains this term simply so you can understand product texts, oil profiles, safety pages and doTERRA language more easily. The glossary does not replace personal guidance, but it helps you avoid getting lost in terminology.

## Important note

LRP should only be set up when you truly understand your routine. It is not required for a conscious start.
